产品介绍

为什么需要「图提取」

电商详情页的图片分散在上百个 DOM 节点里，懒加载、背景图、缩略图混在一起。 手动右键另存既慢又乱，格式还不统一。「图提取」把这件事变成一次点击。

图片分散

主图、SKU 图、详情长图藏在标签、懒加载属性与背景图里，人工翻找费时费力。

无法批量保存

浏览器原生只能单张另存。图提取把全部图片集中成画廊，勾选后一次批量下载。

格式不统一

原图 jpg、webp 混存。图提取在后台统一转码为 PNG，文件名自动补零编号。

核心功能

六个功能，覆盖取图全流程

一键提取

自动触发懒加载滚动，扫描 img、srcset、data-src、背景图等全部来源。

智能过滤

自动排除图标、logo、占位图与小于 100×100 的图片，只留真正的商品图。

集中预览

新标签页网格展示所有图片，带缩略图与真实尺寸，一眼看清每张图。

自由勾选

全选、反选、按需勾选，已选数量实时显示，下载哪些图完全由你决定。

统一 PNG

jpg、webp 原图在后台自动转码为 PNG，保存即用，无需二次转换。

批量下载

一键保存到浏览器下载目录，文件名自动编号：商品图_001.png 起。

安装步骤

四步完成加载

  1. 1

    获取插件文件

    下载本仓库压缩包并解压到本地文件夹（或 git clone 仓库）。

  2. 2

    打开扩展管理页

    打开 Chrome / Edge，地址栏输入 chrome://extensions 回车。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载扩展程序

    点击「加载已解压的扩展程序」，选择插件文件夹即可。
